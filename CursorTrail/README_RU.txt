CursorTrail 7.3.5 Extended

English | Русский

CursorTrail 7.3.5 Extended — расширенная адаптация CursorTrail от
UppyDan (DJU) для World of Warcraft: Legion 7.3.5.

Версия сохраняет исходную Legion-совместимую основу CursorTrail, но
расширяет её функциями и решениями, адаптированными из более поздних
выпусков CursorTrail, переработанным интерфейсом, дополнительными
визуальными эффектами, системой ореола, профилями, локализацией и
исправлениями совместимости для клиента 7.3.5.

  Это не эксклюзивная версия для UWoW. Разработка и основное
  тестирование проводились на сервере UWoW x1, однако аддон предназначен
  для клиента World of Warcraft: Legion 7.3.5 в целом.

Совместимость

-   World of Warcraft: Legion 7.3.5
-   Interface: 70300
-   Код рассчитан на Lua/API клиента Legion 7.3.5 и не использует
    Retail-only API там, где они недоступны в 7.3.5.

Открытие настроек

Введите в игровом чате:

    /ct

или:

    /CursorTrail

Команда /ct без параметров открывает или закрывает основное окно
настроек.

Основные возможности

CursorTrail 7.3.5 Extended состоит из трёх независимых визуальных слоёв.
Каждый слой можно включать и выключать отдельно: использовать только
один слой, любую комбинацию из двух слоёв или все три одновременно.

3D-эффекты

Анимированные игровые модели, следующие за курсором.

Доступные эффекты:

-   Электрический — синий, длинный
-   Электрический — синий, короткий
-   Электрический — зелёный, короткий
-   Электрический — зелёный импульс
-   Световой
-   Призрачный
-   Пульсация — зелёная
-   Пульсация — жёлтая
-   Вихрь — природный
-   Сфера — оранжевая

Настройки:

-   тип эффекта;
-   размер;
-   сдвиг X;
-   сдвиг Y;
-   непрозрачность.

Расширенный каталог 3D-эффектов и их калибровка были адаптированы под
Legion 7.3.5 с использованием более поздних выпусков CursorTrail как
донорских/справочных источников.

2D-эффекты

Плоские текстуры, которые следуют за курсором независимо от 3D-слоя.

Доступные эффекты:

-   Диск
-   Свечение
-   Крест 1
-   Крест 2
-   Вихрь

Настройки:

-   тип эффекта;
-   размер;
-   сдвиг X;
-   сдвиг Y;
-   непрозрачность;
-   цвет.

Ореол курсора

Независимый ореол вокруг курсора, предназначенный для быстрого поиска
указателя в насыщенных боевых сценах.

Формы:

-   Круг
-   Квадрат

Стили:

-   Одноцветный — используется выбранный пользователем цвет;
-   Спектральный — используется встроенный многоцветный спектральный
    градиент.

Настройки:

-   форма;
-   стиль;
-   толщина 1–5;
-   размер;
-   непрозрачность;
-   цвет для одноцветного стиля;
-   включение вращения;
-   инверсия вращения;
-   скорость вращения 1–5.

Ореол вращается как единая текстура. У спектрального круга это визуально
воспринимается как движение цветового потока, а квадрат заметно
вращается вокруг центра курсора. Инверсия меняет направление вращения.

Отображение

Параметр «Показывать только в бою» позволяет автоматически скрывать
включённые эффекты вне боя и показывать их при входе в бой.

Отключённые визуальные слои не обновляют своё положение по курсору,
поэтому не выполняют ненужную работу.

Профили

Аддон поддерживает общие пользовательские профили. Можно создать
профиль, сохранить в него текущие настройки, выбрать ранее сохранённый
профиль и удалить ненужный.

Профили хранятся в CursorTrail_ProfilesDB, а активные настройки
персонажа — в CursorTrail_PlayerConfig. Эти технические идентификаторы
сохранены без переименования для совместимости с существующими
настройками.

Локализация

В аддоне есть русский и английский интерфейсы.

Обычно язык выбирается автоматически по локали клиента WoW:

-   ruRU → русский;
-   enUS, enGB и другие локали клиента → английский.

Для проверки или ручного выбора языка предусмотрен скрытый
переключатель:

    /ct english
    /ct en
    /ct ru
    /ct russian

После изменения языка выполните:

    /reload

Переключатель влияет только на CursorTrail и не меняет язык клиента WoW
или Windows.

Команды

Основные пользовательские команды:

-   /ct или /CursorTrail — открыть/закрыть окно настроек;
-   /ct help — показать встроенный список команд;
-   /ct reload — перезагрузить текущие настройки CursorTrail;
-   /ct reset — сбросить настройки CursorTrail к исходным;
-   /ct combat — переключить режим «Показывать только в бою»;
-   /ct english или /ct en — принудительно выбрать английский после
    /reload;
-   /ct ru или /ct russian — принудительно выбрать русский после
    /reload.

В аддоне также сохранены технические диагностические и калибровочные
команды из линии разработки; при необходимости они отображаются через
/ct help.

Установка

1.  Скачайте подготовленный архив релиза со страницы GitHub Releases.
2.  Распакуйте архив непосредственно в:

    World of Warcraft\Interface\AddOns\

3.  Итоговый путь должен выглядеть так:

    World of Warcraft\Interface\AddOns\CursorTrail\CursorTrail.toc

4.  Запустите или перезапустите World of Warcraft. При необходимости
    включите аддон в списке AddOns на экране выбора персонажа.

Скачивание

Для обычной установки скачивайте подготовленный архив со страницы GitHub
Releases:

    CursorTrail-7.3.5-1.0.0.zip

Не используйте автоматически создаваемые GitHub архивы Source code.zip
или Source code.tar.gz как обычный установочный пакет. Они отражают
структуру репозитория, тогда как релизный ZIP специально собран так,
чтобы его можно было распаковать прямо в Interface\AddOns.
