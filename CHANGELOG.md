# Changelog

## v1.0.0 — Initial public release

First public release of **CursorTrail 7.3.5 Extended** for **World of Warcraft: Legion 7.3.5**.

Compared with the historical CursorTrail 7.3.5.1 base, this release includes:

- a substantially expanded and reorganized configuration interface;
- three independent visual layers: 3D Effects, 2D Effects, and Cursor Halo;
- an expanded selectable 3D effect catalog adapted from later CursorTrail model data and calibrated for Legion 7.3.5;
- independent 2D cursor effects: Disk, Glow, Cross 1, Cross 2, and Swirl;
- an expanded Circle/Square halo system;
- Single Color and Spectral halo styles;
- halo thickness levels 1–5 with a stable outer size;
- high-quality spectral circle and square halo textures created for this adaptation;
- optional halo rotation, reverse direction, and rotation speed control;
- user profiles shared through `CursorTrail_ProfilesDB`;
- per-character active settings retained through `CursorTrail_PlayerConfig`;
- Show only in combat display mode integrated into the redesigned interface;
- Russian and English localization with a manual language override for testing/preference;
- compatibility and model-calibration fixes for the Legion 7.3.5 client;
- cursor-tracking optimization so disabled visual layers are not position-updated;
- preserved compatibility-oriented technical identifiers and SavedVariables names.

Later CursorTrail releases were used as donor/reference sources where appropriate, including 8.2.0.6, 8.3.0.3, and 10.1.0.1. See `CREDITS_AND_LEGAL.md` for provenance details.
